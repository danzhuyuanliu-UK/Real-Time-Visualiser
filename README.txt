GitHub Pages:
1. Create a new public repository (for example: MYTR-Real-Time).
2. Upload all files and the assets folder to the repository root.
3. Repository Settings > Pages > Deploy from a branch > main / root.
4. The site will publish at https://<username>.github.io/<repository-name>/
